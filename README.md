# macOS Glass GNOME Shell Extension

A custom pixel-perfect **macOS Glassmorphism** GNOME Shell extension created for `@dineshyr29-04`.

## ✨ Features
- 🍏 **Apple Glassmorphism:** Translucent glass cards for notifications, Quick Settings, popups, and OSDs.
- ✨ **Specular Edge Sheen:** 1px rim lighting and subtle drop shadows mimicking macOS Tahoe / Sonoma.
- 🛡️ **Top Bar Protection:** Zero height or dimension overrides on the top panel.
- 🚀 **GNOME 46 - 50 Ready:** Supports modern GNOME versions natively.

## 🛠️ Installation

```bash
git clone https://github.com/dineshyr29-04/macos-glass.git
cd macos-glass
./install.sh
```
